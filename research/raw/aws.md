## Strands Agents SDK

- New "Strands harness": pip install strands-harness; create_harness() gives an assembled agent. SDK: pip install strands-agents strands-agents-tools (Python 3.10+); TS needs Node 22+.
- Provider files in strands-py/src/strands/models: anthropic, bedrock, gemini, litellm, llamaapi, llamacpp, mistral, ollama, openai, openai_responses, sagemaker, writer, routing (gh api listing).

Community: CLOVA Studio, MLX, NVIDIA NIM, SGLang, vLLM, xAI. Bedrock is the default provider (core SDK includes BedrockModel by default; others optional deps).

Lists models llama-3.1-70b/8b, llama-3.3-70b, mistral-large, nemotron-70b.
- AWS ML blog 2026-05-26 "Build high-performance generative AI systems with Strands Agents, NVIDIA NIM, and Amazon Bedrock AgentCore" https://aws.amazon.com/blogs/machine-learning/build-high-performance-generative-ai-systems-with-strands-agents-nvidia-nim-and-amazon-bedrock-agentcore/ : uses hosted NIM via build.nvidia.com ("exposing OpenAI-compatible Chat Completion APIs"), Strands multi-agent in a Docker container on AgentCore Runtime, AgentCore Memory + Observability, deployed with SAM template; API Gateway, Lambda, DynamoDB, S3+CloudFront front end.
